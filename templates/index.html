Airtable setup & expected fields

Set AIRTABLE_TOKEN, AIRTABLE_BASE_ID and AIRTABLE_TABLE on the server. Optional AIRTABLE_VIEW narrows the source. The token needs data.records:read and access to the selected base.

Order ID · Date · Customer · Category · Amount USD · Status

Dates: YYYY-MM-DD. Status: Paid, Pending or Refunded. All fields required, amounts in USD. See README for the complete schema.
